# Android 安全审查（2026-11-17）

范围：仅 Android 新增代码与实际 Android/ARM64 原生依赖。不修改或替代既有 Mac 安全结论。真实订阅联网由用户执行；本轮使用虚构本地节点和隔离模拟器。

## 审查中发现并修复

- 初始原生依赖扫描报告 7 项可达漏洞：brotli 解压内存消耗、compress 解码 panic、x/net HTTP/2 问题。Android 模块单独升级 brotli 1.2.7、compress 1.20.2、x/net 0.60.0 及其锁定传递依赖。升级后按 Android/ARM64 源码扫描为 0 项可达漏洞。模块图仍报告 6 项未被代码调用的漏洞，不等同于所有上游模块均无漏洞。
- 原生 TUN 默认关闭路径会尝试 Linux 网络配置清理。明确启用外部配置模式；只有 VpnService.Builder 管理虚拟网卡，原生只拥有 dup 出来的描述符。
- 禁用原生 Android netlink 路由监控，改为系统逐套接字保护，避免无 Root 环境权限失败与隧道回环；保护失败即中止该连接。
- 重复启动指令原先可能 stopSelf 结束已有连接，现改为幂等忽略。
- 普通网络读取超时不能约束慢速连续输入；增加总读取期限、输入上限和取消检查。
- 补齐旧版 Android 禁止备份配置与新版数据迁移排除规则，防止加密数据与设备绑定密钥分离迁移。
- 静态检查误要求 VPN 前台服务使用精确闹钟权限。按官方 systemExempted 的 VPN 例外处理，仅在该服务上注明运行条件；不引入设备管理、精确闹钟或 Root 权限。
- 测试程序发现自己的 finish 调用早于 finally 清理。已调整测试顺序，并增加“已有配置则拒绝测试”，测试辅助组件只存在于独立测试 APK。

- 最后一轮 Reality/Vision 的 race/checkptr 测试暴露 sing-vmess 的 uintptr 跨函数返回导致指针检查 fatal error。未关闭检查；Android 独立 third_party 副本改为保留 unsafe.Pointer、使用 unsafe.Add，并校验 TLS 私有字段类型与结构边界后访问。修正后完整协议环回 race/checkptr 与 vet 均通过。TLS 内部布局仍属版本相关实现，升级 Go/uTLS 时必须重验。

- 订阅节点/策略组显示名另限 512 字节，拒绝控制符和方向控制符；服务器名称限 253 字节，防止超长标签造成界面布局压力或伪装选项。

## 防护边界

- 单一系统 VPN、独立隧道进程、串行启停、20 秒启动期限、8 秒停止兜底。兜底只结束本应用隧道进程，Android 释放所有描述符；不结束 UI 或其他应用。
- 服务不导出，只允许本 UID 查询/停止。无外部监听、Root、开机启动或自动重连。系统始终开启 VPN 由用户控制，应用不擅自开启/关闭。
- YAML ≤1 MiB，节点≤2048，策略组≤128，引用及循环验证；未知节点参数拒绝导入。运行配置由白名单模型重建，外部控制器、文件路径、远程规则、脚本、DIRECT 回退不执行。
- HTTPS 订阅，证书正常校验，禁用自动重定向。输入地址由用户显式提供；不存在远程自动导入入口。
- Android Keystore AES-GCM，原子加密写入应用私有 noBackup 目录；界面禁止系统截屏与自动填充敏感链接。日志不写订阅、UUID、密码和访问记录。
- 节点测试仅在停止 VPN 后手动执行，拒绝其他活动 VPN；固定 HTTPS 测试目标、禁止重定向、20 秒期限、下载最多约5 MiB，失败不改为直连。
- APK 含 ARM64 与 x86_64 动态库，无 Python/Go 外置解释器或命令依赖；签名密钥和密码保存在 private/，不打包分发。
- 供应链核验：43 个实际使用的下载依赖源码目录与 go.sum 的 h1 摘要一致；4 个本地模块另行审核。独立 sing-box 源码树逐文件匹配固定 SHA-256 的原始归档；Vision vendor 仅修改已记录的两个实现文件和说明文件。Go 的通用 go mod verify 对本地占位模块 privateproxy/core 报缺少缓存 ziphash，因此新增开发用 verifydeps 工具校验实际下载依赖，没有把本地替换源码冒充远程已校验模块。

- Go：配置边界、外部配置注入、TLS 不信任证书、响应/下载限额及保护失败测试通过；race 与 vet 检查通过。另以安卓转换器生成的实际出站选项完成 VLESS Reality/Vision、Trojan 的 TCP/UDP 主机环回收发；不以此替代手机联网验收。
- YAML fuzz：初轮约 368477 次输入，30 秒测试，无崩溃；最终边界修复后另跑约 81276 次输入，20 秒测试，无崩溃。

- 无法保证应用永不崩溃或阻止操作系统/硬件故障。保护目标是异常时释放本应用隧道，避免永久代理残留；用户自己设置的系统断网保护仍会生效。

证据日志位于项目 .cache/android-*.log；不得将包含用户真实配置的日志补入交付文件。

## 0.1.1 TUN 自回环修复及重新验收

用户实机反馈同节点测速成功、TUN 开启后全站不通。此前测试仅证明节点出站和 TUN 生命周期，未覆盖应用经实际 Android TUN 的完整数据路径。

新增隔离模拟器测试复现 TCP 超时。根因为缺少 route.auto_detect_interface=true：sing-box 的 dialer 仅在该配置开启时，才将平台保护回调加入真实 socket Control。实现保护函数本身不足以保证生效；原版的节点连接重新进入 TUN 造成回环。

修复后对 TCP/UDP 协议测试增加了实际保护调用计数断言；在 emulator-5580 中，以出站白名单阻止外网，只允许宿主 10.0.2.2 的回环模拟网关和虚拟 TUN。用户明确授权该本机闭环复测。应用经 Android 系统 TUN、Reality/Vision、回环 HTTP/UDP 服务的完整往返通过；正常停止、重复启动、强制进程死亡、崩溃后重连和授权撤销通过。

临时 trace 库只通过 debug 构建参数注入，release 始终绑定正式日志关闭的 AAR。没有将合成网关、测试 Activity 或临时详细日志打入交付 APK。新增 TUN 网页验证仅在用户确认后访问固定 Apple HTTPS 页面；执行验证时仍可随时停止 VPN。

真实手机、外部 DoH 的实际可达性与私人节点仍由用户验收，不以本机闭环替代。发布构建、单元测试、静态检查和 Android/ARM64 漏洞复扫通过。

## 0.1.2 批量测试审查

批量延迟最多并发 2 项，下载固定串行；任务按需创建，不预建几千个内核实例。每个原生 ProbeJob 单次使用，取消会传播到内核与 HTTP 请求；本机环回测试验证了取消能中断实际节点 TLS 握手。输入快照在整批测试内固定，测速时禁止切换配置或开启本应用 VPN。界面离开前台、网络变化或发现其他 VPN 时取消；不缓存或记录私人订阅到日志。

每批开始前再次确认目标服务和流量上限。测试固定 Apple / Cloudflare HTTPS 目标、保持证书校验、不跟随重定向、不回退直连；失败结果不填入虚构速度。延迟和下载数据分开存储与排序，明确测试时间与失败状态，手动选用才切换默认出口。完成/取消后释放任务及内核，迟到结果不覆盖新批次。

0.1.2 已通过全量 Go race/checkptr、vet、6 项 Kotlin 发布单元测试和 Lint（0 错误、1 条构建工具升级提示）。隔离 Android 36 ARM64 模拟器完成 20 个真实 JNI ProbeJob 的预取消批量运行，未产生网络 IO；系统 TUN 的完整 HTTP/TCP、UDP 及生命周期闭环回归再次通过。正式签名 APK 的同签名覆盖安装、冷启动、正式原生库一致性、权限、签名和 16 KiB 静态对齐检查通过。没有使用私人订阅或访问外网，真实下载速度和手机性能仍由用户验收。
