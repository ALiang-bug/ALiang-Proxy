# Android 实现与验收记录

## 用户要求

- 新增 Android 客户端；未经新授权不得修改已有 Mac 客户端。
- 使用现有 Clash YAML / HTTPS 订阅，支持 VLESS Reality/Vision、Trojan、策略组和节点选择。
- 使用系统 VpnService 处理 Wi-Fi 与蜂窝流量，无 Root。
- 交付包含原生内核的签名 APK；手机不依赖 Python、Go、Java 开发环境或外置命令。
- 开发后主动进行漏洞筛查、防护与代码评审；联网节点验收由用户执行。

## 架构

Kotlin 原生界面 → 本地配置解析和验证 → 加密存储 → VpnService → 包含在 APK 中的代理内核。
平台层必须保护远端套接字防止隧道回环；内核只在资源和配置验证完成后启动。
内核版本、许可证、构建标签、供应链摘要须在接入前验证，不能把已有 Apple 补丁直接当作 Android 接口。

## 必须验证的安全不变量

1. 隧道文件描述符与核心实例只有一个所有者；启动失败、撤销授权、停止、销毁都执行幂等清理。
2. 正常停止和进程死亡不会遗留由应用创建的永久系统代理、DNS 或路由设置。
3. 默认不自动连接、不请求开机启动、不自动启用始终开启 VPN 或系统断网保护。用户手动设置的系统断网保护不可由应用擅自取消。
4. 前台通知提供停止入口；反复连接、并发停止、切换网络不能产生孤儿内核或重复隧道。
5. 私人订阅、UUID、密码不得写入日志、通知、Intent、公开构建和诊断报告。
6. 配置限长、下载限时限长、只用 HTTPS、检查状态码和重定向；订阅更新失败保留有效旧配置。
7. 导入不能开启远程控制、LAN 监听、外部进程、任意文件访问或任意远程规则下载。
8. 密钥由 Android Keystore 管理；配置在私有目录加密保存，禁止备份敏感内容。
9. 主线程不执行解析、网络、核心启停；异常转换为可恢复错误，不能伪造已连接状态。
10. 本地/模拟测试不连接私人节点、不改 Mac 的代理、DNS 或路由。

## 验收证据要求

- 解析与策略组验证：非法输入、循环、重复、超限、敏感字段不回显。
- 生命周期：失败回滚、重复启停、授权撤销、服务重建和进程死亡。
- 网络：用环回测试服务器验证 TCP、UDP 和套接字保护；真实订阅由用户联网验收。
- 发布：APK 签名校验、ABI/动态库依赖、权限/导出组件检查、凭据扫描、依赖漏洞扫描。
- 代码评审：逐项检查资源所有权、并发、配置边界、存储、JNI 边界和更新行为，并记录未解决问题。
- 安装：APK 可直接安装；更新沿用签名密钥；提供 SHA-256 和简短安装说明。
